# AskPlex-Lite

AskPlex-Lite is based on [askplex](https://github.com/andresponte/askplex) and aims to streamline the communication components.
It also allows connection via https://app.plex.tv even if you don't have a domain.
For more details, please see [this article](https://qiita.com/kuro4/items/ecf8df5199ddbb62c6cf).
