# Plextreme

Plextreme is based on [askplex-lite](https://github.com/Kuro4/askplex-Lite) which, in turn, is based on [askplex](https://github.com/andresponte/askplex).
Askplex-lite took askplex and improved the connectivity performance by caching the cocnnection and allowing non-local 
connections via https://app.plex.tv even if you don't have a domain. For more details, please see [this article](https://qiita.com/kuro4/items/ecf8df5199ddbb62c6cf). 

Plextreme extends askplex-lite by vastly improving the searching and UI experiences. The search is now more feature
rich, allowing playlists/artist collections to be played in shuffle mode directly
("Plextreme shuffle playlist my tunes"), and the searching is more robust with several fallback options using
increasingly liberal matching criteria.
